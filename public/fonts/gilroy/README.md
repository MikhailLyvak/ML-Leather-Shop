# Gilroy (optional, licensed)

The UI uses `font-gilroy` across the storefront. Place **your licensed** Gilroy files here:

- `Gilroy-Regular.woff2` (400)
- `Gilroy-Medium.woff2` (500)

When these files exist, they take priority over the bundled Manrope fallback in `public/fonts/manrope/`.

Do not commit font files unless your license allows redistribution in the repository or Docker image.
